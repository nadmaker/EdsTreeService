7. Ed's-specific methodology
Patterns this fork established or confirmed, beyond EBS §7 (which still applies: the register is a gate; overrides are recorded where the value lives; defaults are content; prefer Mechanism A; measure on pixels; verify the probe; one source of truth).
7.1 A sibling client's repo can be the fork source. This fork was cut from the EBS build, not from nadmaker/Frame-sites, because the template repo was ~1,100 lines behind on shared files. git archive HEAD exports the COMMITTED tree only — no .git, no node_modules, no build output, and none of another session's uncommitted edits — which is a cleaner Step −1 than a folder copy. Delete the tracked .env from the export before the first commit.
7.2 A style guide is a claims source. The guide arrived titled for a different company and carried "Certified Arborists", "Emergency Storm Damage Removal", an "emergency/24-7 banner" and a Triangle market assumption as EXAMPLES. Its tokens and rules were adopted; every example string was checked against the register and refused. Style direction is raw material exactly as a competitor reference is.
7.3 Every photo slot ships a generated placeholder. Neither the previous client's photographs nor the template's original ones may appear, and a required image field cannot be empty, so scripts/placeholders.mjs renders a branded card per slot (and the wordmark and favicon). Replacing the file is the whole swap; the og card follows automatically.
7.4 Scripted, asserted copy passes. Sixty-plus wrapper edits were applied by a script that asserts each literal occurs exactly once, so a drifted file fails loudly. Two things broke it and are worth knowing on this repo: some files are CRLF (the builders, the og card) while most are LF — normalise before matching and restore on write; and a comment-stripped view of a file hides comment lines INSIDE a block, so read the raw lines before composing an exact-match literal.
7.5 Tooling limits that cost time: the shell tool truncates commands past roughly 8 KB, so large files are written through the file tool, not heredocs; piping a dev server into head kills the server when head exits — log to a file instead; tsc needs Astro's generated types, so run a build before trusting a "clean" tsc on a fresh checkout.
7.6 Re-author, do not blank. With credentialTitle empty, nine former consumers were rewritten around the five cleared claims. Leaving a slot empty and letting consumers render "" produces sentences with holes and no build error.
